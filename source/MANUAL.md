## 1. 项目概览

### 1.1 是什么

**2D方块世界**是一款运行在浏览器里的横版沙盒游戏。玩家出生在程序生成的世界中，砍树、挖矿、合成工具、建造建筑，并在其中管理生命与饥饿。

- **零安装**：构建产物是单个 `index.html`（约 1.5 MB），双击即玩，也可直接部署到任意静态托管
- **零外部素材**：所有贴图由 Canvas 程序化绘制（16×16 像素风），所有音效由 Web Audio 实时合成
- **零后端**：存档写入浏览器 localStorage，不需要服务器
- **单一运行时依赖**：Phaser 3（MIT 许可）

### 1.2 核心特性

| 特性 | 说明 |
|---|---|
| 程序化世界 | 512×128 格，两阶价值噪声地形 + 洞穴 + 沙地 + 树木，同一 seed 结果完全一致 |
| 四种矿物 | 煤 / 铁 / 金 / 钻石，按世界绝对深度分布，越深越稀有 |
| 完整合成链 | 8 条原版式有形配方（按图案摆放、支持水平镜像），木头→木板→木棍→工作台→四级镐 |
| 工具门槛 | 等级不足能破坏但无掉落；等级越高挖得越快 |
| 地下光照 | 越深越暗，火把在黑暗中照出光圈；洞穴内显示暗色岩壁 |
| 生存要素 | 摔落伤害、饥饿消耗、自然回血、苹果食物、死亡重生（物品保留） |
| 操作手感 | 潜行防坠落、双击 / Ctrl 疾跑、分轴 AABB 碰撞无穿墙 |
| 区块渲染 | 16×16 格区块离屏 Canvas 缓存，只重绘脏区块，按视野动态创建/回收 |
| 增量存档 | 只保存玩家改动的方块 diff，10 秒自动保存，存档损坏自动回退 |

### 1.3 目标体验

打开网页 10 秒内可上手；一局完整的“撸树 → 合成 → 挖矿 → 建造 → 存档续玩”流程不卡壳。设计上刻意砍掉怪物战斗、熔炉冶炼、工具耐久等系统，把有限工作量集中在“每个功能都能稳定跑通”。

## 2. 快速开始

### 2.1 直接玩（无需任何环境）

用 Chrome / Edge 打开构建产物：

```
dist/index.html
```

双击即可运行（`file://` 协议亦可），无需服务器。

### 2.2 从源码运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 产出 dist/index.html（单文件）
npm run preview    # 预览生产构建
npm run typecheck  # TypeScript 类型检查（tsc --noEmit）
npm test           # 逻辑单元测试
```

> 源码版 `index.html` 引用 `/src/main.ts`，必须经 `npm run dev` 启动后访问（浏览器无法直接执行 TypeScript）；构建产物才是可直接双击的单文件。

### 2.3 部署到静态托管

`npm run build` 后，把 `dist/index.html` 放到任意静态托管（GitHub Pages / Netlify / Vercel / 对象存储）即可。`vite.config.ts` 中 `base: './'` 使用相对路径，放在任意子目录都能正常加载。

### 3.3 浏览器行为屏蔽

- 右键菜单屏蔽
- 方向键 / 空格导致页面滚动（由 Phaser `addKeyCapture` 接管）
- `Ctrl + A/D/S` 的浏览器默认行为（阻止后补发克隆键盘事件，保证 Ctrl 疾跑仍生效）

> 说明：`Ctrl + W` 是浏览器关闭标签页的快捷操作，网页无法可靠拦截，因此疾跑同时提供“双击方向键”方案。

## 4. 玩法系统详解

### 4.1 一局完整流程

1. **撸树**——走到树旁，对准树干按住左键，收集木头
2. **合成**——按 `E` 打开背包，照标题页「合成表」的图案摆放：
   - 木头 → 木板 ×4
   - 木板竖放两格 → 木棍 ×4
   - 木板填满 2×2 → 工作台
3. **放工作台**——快捷栏选中工作台，右键放地上；再右键它打开 3×3 合成
4. **做镐**——顶排 3 个材料 + 中列 2 根木棍 → 对应等级镐；用石镐向下挖煤、铁、金、钻石
5. **照明**——煤 + 木棍 → 火把 ×4，放到地下照亮周围
6. **生存**——注意饥饿（疾跑消耗 ×3），树叶有 15% 概率掉苹果；摔落超过 3 格受伤
7. **续玩**——进度自动保存，关页面后从标题页「继续游戏」恢复

### 4.2 方块与物品

方块 id 范围为 1–99，物品 id ≥ 100（0 为空气）。

**方块（14 种）**

| 方块 | 是否实体 | 手挖时间(s) | 掉落门槛 | 掉落 |
|---|---|---|---|---|
| 草方块 | 是 | 0.5 | 无 | 泥土 |
| 泥土 | 是 | 0.5 | 无 | 泥土 |
| 沙子 | 是 | 0.5 | 无 | 沙子 |
| 石头 | 是 | 3.0 | 木镐 | 石头 |
| 木头 | 是 | 0.8（固定） | 无 | 木头 |
| 树叶 | 是 | 0.3（固定） | 无 | 树叶；15% 额外掉苹果 |
| 木板 | 是 | 0.8（固定） | 无 | 木板 |
| 工作台 | 是 | 0.8（固定） | 无 | 工作台 |
| 火把 | **否**（可穿过） | 0.1（固定） | 无 | 火把 |
| 煤矿石 | 是 | 3.0 | 石镐 | 煤 |
| 铁矿石 | 是 | 3.0 | 石镐 | 铁矿石 |
| 金矿石 | 是 | 3.0 | 铁镐 | 金矿石 |
| 钻石矿石 | 是 | 3.0 | 铁镐 | 钻石矿石 |
| 基岩 | 是 | 不可破坏 | — | — |

**工具挖掘时间表（秒）**

| 方块 | 手 | 木镐 | 石镐 | 铁镐 | 钻石镐 |
|---|---|---|---|---|---|
| 石头 / 各类矿石 | 3.0 | 1.2 | 0.9 | 0.7 | 0.5 |

**物品（7 种）**

| 物品 | 说明 |
|---|---|
| 木棍 | 合成材料 |
| 苹果 | 食用，+3 饥饿（20 单位制 +6） |
| 煤 | 合成火把 |
| 木镐 / 石镐 / 铁镐 / 钻石镐 | 工具等级 1 / 2 / 3 / 4 |

- 所有物品堆叠上限 64
- 工具无耐久度（简化）
- 工具等级不足时：方块可破坏、但不产出掉落物（还原经典手感），并给出一次性提示

### 4.3 合成表（8 条，有形配方）

配方按图案匹配位置，支持水平镜像；图案能放进当前网格即可合成。2×2 随身合成可做前 4 条，3×3 工作台可做全部。

| 配方 | 图案 | 网格 |
|---|---|---|
| 木头 → 木板 ×4 | `W` | 2×2 |
| 木板 → 木棍 ×4 | `P` / `P`（竖放） | 2×2 |
| 木板 → 工作台 | `PP` / `PP` | 2×2 |
| 煤 + 木棍 → 火把 ×4 | `C` / `S`（竖放） | 2×2 |
| 木板 + 木棍 → 木镐 | `PPP` / `.S.` / `.S.` | 3×3 |
| 石头 + 木棍 → 石镐 | `MMM` / `.S.` / `.S.` | 3×3 |
| 铁矿石 + 木棍 → 铁镐 | `MMM` / `.S.` / `.S.` | 3×3 |
| 钻石矿石 + 木棍 → 钻石镐 | `MMM` / `.S.` / `.S.` | 3×3 |

- 每次点击结果格消耗一份材料，剩余材料留在格内可连续合成
- 材料不足时结果格置灰；凭空点材料不会出货
- 不做熔炉：铁/金矿石直接作为合成材料

### 4.4 生存规则

**数值体系**：生命与饥饿内部均用 20 单位制，1 单位 = 半格。

| 项目 | 规则 |
|---|---|
| 生命 | 10 颗心（20 单位） |
| 饥饿 | 10 格（20 单位） |
| 摔落伤害 | 下落超过 3 格起算，每超 1 格扣 0.5 心（1 单位） |
| 饥饿消耗 | 行走 0.06 单位/秒；跳跃 0.12 单位/次；疾跑消耗 ×3 |
| 自然回血 | 饥饿 ≥ 18 单位（9 格）时，每 4 秒回 0.5 心 |
| 饥饿扣血 | 饥饿 = 0 时每 4 秒扣 0.5 心，且生命最低保留半颗心（不会饿死） |
| 进食 | 苹果 +6 单位饥饿；0.5 秒进食冷却；不饿也能吃（溢出封顶） |
| 死亡 | 生命归零进入死亡界面；重生回出生点，生命与饥饿重置，**物品保留** |

> 设计取舍：死亡不做物品掉落，调整为休闲向体验；不做饥饿致死，避免玩家在探索中被迫反复进食。

### 4.5 光照

- 地下按深度叠加暗色遮罩：玩家位于地表以下超过 8 格开始变暗，最大不透明度 0.88
- 视野内的每个火把用径向渐变在遮罩上“抠洞”提亮，光圈半径 7 格
- 遮罩由独立相机渲染，不影响 HUD

### 4.6 收集进度

HUD 显示当前深度；四种矿石（煤/铁/金/钻石）首次掉落入包时点亮对应图标，集齐时给出一句提示。

## 5. 世界生成

### 5.1 确定性随机

所有随机数来自整数哈希（`hash2i`），同一 seed 生成结果完全一致，因此存档只需保存 seed 与玩家改动。

### 5.2 生成步骤

1. **地表高度线**：两阶价值噪声叠加（大起伏 ±8 + 细节 ±4），钳制在 30–95 行，基线 64
2. **列填充**：空气 → 草/沙 → 泥土（4 格）→ 石头 → 底部 2 行基岩
3. **沙地斑块**：噪声阈值决定整列材质（沙漠区域）
4. **洞穴**：两层 2D 噪声加权（0.62 / 0.38），超过阈值 0.65 挖空；不穿透地表与基岩层
5. **矿石**：2×2 粗粒度哈希做“矿脉门控”（30% 概率进入矿脉），再按世界绝对 y 区间与概率生成
6. **种树**：草方块地表随机生成（12% 概率、最小间隔 5 格、两侧高差 ≤1）；木干 3–5 格 + 分层树叶团（角部随机缺角）

### 5.3 矿石分布（世界绝对行）

| 矿石 | y 区间 | 每格概率 |
|---|---|---|
| 煤 | 70 – 106 | 1.6% |
| 铁 | 80 – 114 | 1.2% |
| 金 | 96 – 121 | 1.0% |
| 钻石 | 108 – 125 | 1.2% |

> 采用绝对行而非“地表以下格数”，保证四种矿石在全图任意列都可达（高山列也不会缺失深矿）。

## 6. 技术架构

### 6.1 技术栈

- **Vite 5** + **TypeScript 5** + **Phaser 3.90**（唯一运行时依赖）
- `vite-plugin-singlefile`：构建时把 JS/CSS 全部内联进单个 HTML

### 6.2 分层设计

```
场景层  BootScene（生成纹理）→ TitleScene（标题/合成表/说明）→ GameScene（主游戏）
系统层  Mining（挖掘/放置） Inventory（背包） Crafting（合成）
        Survival（生命/饥饿） Lighting（光照） Save（存档） Sfx（音效）
世界层  WorldGen（地形生成） World（方块数据 + diff） Chunk（区块离屏渲染）
实体层  Player（状态与操控） Physics（AABB 分轴碰撞）
表现层  Hud / InventoryUI / PauseMenu / DeathScreen / common（通用控件）
```

### 6.3 关键实现

**物理**：自定义瓦片 AABB 碰撞，先解 X 轴再解 Y 轴；地面/空中使用不同的加速度与摩擦力；最大下落速度钳制 480 px/s。

**渲染**：世界以 16×16 格为一个 chunk，每个 chunk 渲染到离屏 Canvas 并作为纹理平铺。方块改动时只把所在 chunk 标脏重绘；相机移动时按视野动态创建/回收 chunk，避免一次性铺满 512×128 全图。

**双相机**：`worldCam`（2 倍缩放、跟随玩家、带世界边界）渲染世界；`uiCam` 渲染全部 UI 与光照遮罩。两个相机互相 `ignore` 对方对象。

**视差背景**：天空、太阳、云层、远近山共 5 层，按 0.15 / 0.3 / 0.6 倍速滚动，每帧贴到屏幕位置。

**程序化纹理**：`textures.ts` 用 Canvas 2D 绘制全部 16×16 纹理——草方块顶部绿带、矿石底色+斑点、木头竖纹、树叶深浅绿、工具像素图形、心/饥饿图标、裂纹帧、夕阳光晕、粒子等，启动时一次性生成并注册为 Phaser 纹理。

**程序化音效**：`sfx.ts` 用 Web Audio 合成 10 种 8-bit 音效（挖掘/破坏/放置/跳跃/受伤/进食/点击/收集/合成/死亡），方波+噪声+音量包络；同时发声上限 8 路防爆音，支持 `M` 静音。

## 9. 存档机制

- **键名**：`blockworld2d_save_v1`，当前格式版本 `2`
- **保存时机**：每 10 秒自动保存；暂停菜单手动保存
- **保存内容**：

```json
{
  "version": 2,
  "seed": 123456789,
  "blockDiffs": { "格子索引": "方块id" },
  "player": { "x": 0, "y": 0, "health": 20, "hunger": 20 },
  "inventory": [{ "id": 1, "count": 12 }, null, "..."],
  "hotbarIndex": 0,
  "stats": { "coal": true, "iron": true },
  "savedAt": 0
}
```

- **只存 diff**：世界本身由 seed 重新生成，只叠加玩家改动过的方块，存档体积极小
- **读取校验**：全字段白名单 + 数值钳制——非法的方块 id、物品 id、格子索引、坐标、生命/饥饿值全部过滤或钳制；任何异常都安全回退为新游戏，不会白屏
- **写入失败**：localStorage 满了或被禁用时提示一次

## 10. 性能设计

| 措施 | 效果 |
|---|---|
| 区块离屏 Canvas + 脏标记 | 改一格只重绘 16×16 区域，不重绘全图 |
| 区块按视野动态创建/回收 | 内存占用与视野大小相关，不随世界尺寸线性增长 |
| 复用粒子发射器 | 连续挖放不反复创建对象，减少 GC |
| 单纹理复用 | 每种方块只有一张 16×16 纹理，靠平铺绘制 |
| 相机 roundPixels | 像素风画面稳定，无亚像素抖动 |
| 音效并发上限 8 路 | 连续挖掘不爆音、不堆积 AudioNode |
